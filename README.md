# Практична робота №16–17 — ProductFlow

Навчальний вебзастосунок для керування каталогом товарів.

## Запуск
1. Відкрийте папку `lab-16-17` у Visual Studio Code.
2. Відкрийте `index.html` у браузері або запустіть через розширення Live Server.
3. Додавайте, редагуйте, видаляйте та переглядайте товари.

## Реалізовані операції CRUD
- Create — додавання товару.
- Read — перегляд товарів, пошук і фільтрація.
- Update — редагування товару.
- Delete — видалення товару.

## Зберігання даних
Для спрощеної клієнтської реалізації використовується `localStorage` браузера. Дані зберігаються між перезавантаженнями сторінки в тому самому браузері.

## Важливо
Цей варіант демонструє клієнтську реалізацію CRUD. Він не замінює серверну частину Node.js/Express та базу даних MySQL, передбачені методичними вказівками.
